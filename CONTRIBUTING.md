# Contribuir

## Flujo de ramas

- `main`: produccion.
- `dev`: integracion de ejercicios.
- `alumno/nombre-apellido/ejercicio-001`: rama personal de estudiante.

## Commits

Usa Conventional Commits:

- `feat:` nueva solucion o nuevo ejercicio.
- `fix:` correccion de una solucion.
- `docs:` evidencia, README o documentacion.
- `refactor:` mejora interna sin cambiar resultado.
- `test:` validaciones o pruebas.
- `chore:` ajustes menores permitidos.

Ejemplos:

```bash
git commit -m "feat(mongodb): resolver ejercicio 012"
git commit -m "docs(evidencia): agregar capturas de aggregation"
git commit -m "fix(consulta): corregir filtro por categoria"
```

## Regla principal

Las entregas solo se aceptan dentro de `resoluciones/nombre-apellido/`.
