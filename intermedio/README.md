# Nivel Intermedio

Este nivel contiene 50 ejercicios de MongoDB para practicar consultas avanzadas, aggregation, indices, validacion y relaciones por referencia/embebido.

## Progresion

- Ejercicios 001-010: base del nivel.
- Ejercicios 011-020: combinacion de conceptos.
- Ejercicios 021-030: casos con mas datos y validacion.
- Ejercicios 031-040: escenarios de analisis y decisiones.
- Ejercicios 041-050: integracion del nivel.

Cada ejercicio debe resolverse dentro de su carpeta `resoluciones/{usuario-github}/`.
