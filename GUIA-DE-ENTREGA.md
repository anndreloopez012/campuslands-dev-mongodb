# Guia de entrega

## Correcto

```text

intermedio/ejercicio-020/resoluciones/maria-lopez/README.md

```

## Incorrecto

```text

```

## Pasos

1. Actualiza `dev`.
2. Crea tu rama personal.
3. Resuelve dentro de la carpeta del ejercicio.
4. Guarda todo dentro de `resoluciones/{usuario-github}/`.
5. Haz commit con Conventional Commits.
6. Haz push de tu rama.
7. Abre Pull Request hacia `dev`.
