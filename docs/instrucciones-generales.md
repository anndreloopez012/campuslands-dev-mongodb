# Instrucciones generales

Este repositorio usa MongoDB como herramienta principal de aprendizaje NoSQL.

## Entregas

- Una carpeta por estudiante dentro de cada ejercicio.
- Comandos reproducibles.
- Explicacion corta de decisiones.
- Evidencia cuando el ejercicio lo requiera.

## Validacion

Antes de abrir PR revisa:

- Tu archivo corre en `mongosh`.
- No modificaste archivos base.
- Tu PR apunta a `dev`.
- Tu estructura cumple `resoluciones/{usuario-github}/`.
